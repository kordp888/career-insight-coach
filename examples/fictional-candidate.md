# Fictional Candidate Example

> 이 문서는 제품 흐름을 설명하기 위한 가상 예시입니다. 실제 인물이나 기업 지원 기록이 아닙니다.

## Target Role

AI Product Manager

## Sample Experience

### 프로젝트 A: AI 기반 서비스 기획

**상황**  
사용자가 필요한 정보를 찾기 위해 여러 화면을 반복해서 이동해야 하는 문제가 있었습니다.

**문제**  
기능이 부족한 것이 아니라 사용자가 어떤 순서로 행동해야 하는지 명확하지 않았습니다.

**판단**  
기능을 추가하기 전에 핵심 사용자 흐름을 단순화하고 실제 사용 과정에서 먼저 검증하기로 했습니다.

**행동**
- 사용자 흐름 정리
- 핵심 화면 범위 축소
- 프로토타입 제작
- 사용자 피드백 정리

**결과**  
핵심 탐색 과정에서 발생하는 혼란 지점을 구체적인 개선 항목으로 정리했습니다.

**직무 연결**  
문제를 기능 목록으로 바로 전환하지 않고, 사용자 행동과 검증 순서를 먼저 설계한 경험으로 설명할 수 있습니다.

## Example Insight

> 복잡한 문제를 한 번에 해결하려 하기보다, 사용자가 실제로 행동하는 핵심 흐름을 먼저 분리하고 검증 가능한 단위로 만드는 방식으로 문제를 해결한다.

## Possible Outputs

### Resume Bullet
사용자 탐색 과정의 병목을 분석하고 핵심 흐름 중심의 프로토타입을 설계하여 주요 개선 포인트를 도출.

### Portfolio Message
기능을 늘리는 대신 검증해야 할 사용자 행동을 먼저 정의했습니다.

### Interview Question
"기능 추가보다 사용자 흐름 개선을 우선한 이유는 무엇이었나요?"

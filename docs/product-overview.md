# Product Overview

## One-line Definition

산업·기업·직무를 이해하고, 지원자의 실제 경험에서 직무 인사이트를 발견해 취업 문서와 면접 준비로 연결하는 AI Career Insight Coach.

## Target Users

### 취업 준비생
- 내 경험을 제대로 정리하고 싶은 사람
- 어떤 경험을 어떤 직무에 연결해야 할지 어려운 사람
- 기업별 지원 문서를 더 구체적으로 만들고 싶은 사람
- 면접까지 재사용 가능한 스토리를 만들고 싶은 사람

### 강사 / 취업 컨설턴트
- 학생의 직무 이해도와 경험 정리 수준을 빠르게 파악하고 싶은 사람
- 반복적인 문장 첨삭보다 사고 과정 코칭에 집중하고 싶은 사람
- 학생이 스스로 답을 발견하도록 지원하고 싶은 사람

## Product Principles

1. 생성보다 발견을 먼저 한다.
2. 경험을 먼저 꺼내고 산업·기업·직무 이해와 연결한다.
3. 사용자의 실제 경험과 판단을 중심에 둔다.
4. 최종 문서보다 재사용 가능한 인사이트를 남긴다.
5. 공개 예시는 개인정보가 없는 가상 데이터만 사용한다.

## High-level User Journey

### 1. Experience Discovery
기억나는 경험을 이야기로 꺼내고, 코치가 한 번에 하나씩 물어 본인 역할, 판단 이유, 실행 순서, 수정, 결과 확인 방법을 구체화한다. 지원 직무가 없어도 시작한다.

### 2. Target Understanding
산업, 기업, 직무/JD를 순서대로 이해한다. 각 분석은 핵심 요약, 상세, 근거와 확인 범위, 사회적 의미, 나와 연결하는 질문으로 구성한다. 개인적 의미는 사용자가 직접 쓴다.

### 3. Relevance Discovery
직무가 요구하는 역량과 경험의 연결 가능성을 탐색한다.

### 4. Insight Articulation
반복되는 강점, 문제 해결 방식, 의사결정 패턴을 언어화한다.

### 5. Output Structuring
발견한 내용을 이력서, 자기소개서, 포트폴리오 형태로 정리한다. 면접 답변 작성은 후속 확장 기능이다.

## Expected Value

기존 AI 문서 생성 도구의 핵심 질문이 "무엇을 써줄까?"라면, 이 프로젝트는 "당신의 경험에서 무엇을 발견해야 하는가?"를 먼저 묻습니다.

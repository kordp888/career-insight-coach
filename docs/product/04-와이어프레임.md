# 와이어프레임

목적: 현재 v1 화면 구조를 고정하고 v1.1 상세 디자인의 기준을 만듭니다.
표기: `[버튼]`, `(입력)`, `[ ] 체크`, `{상태}`, `... 반복 영역`

## 공통 데스크톱 셸

```text
┌───────────────┬───────────────────────────────────────────────────────┐
│ 커리어코치    │ 브라우저 저장·AI 전송 안내              [예시로 보기] │
│               ├───────────────────────────────────────────────────────┤
│ 홈            │ 산업  기업  직무  경험  연결  인사이트  결과         │
│               │ ━━━   ━━━   ━━━   ━━━   ━━━   ━━━━━   ━━━         │
│ 분석          ├───────────────────────────────────────────────────────┤
│  산업 분석    │                                                       │
│  기업 분석    │                  화면별 본문                          │
│  직무 분석    │                                                       │
│               │                                                       │
│ 나의 경험     │                                                       │
│  경험 정리    │                                                       │
│  역량 연결    │                                                       │
│  인사이트     │                                                       │
│               │                                                       │
│ 결과          │                                                       │
│  이력서       │                                                       │
│  자소서       │                                                       │
│  포트폴리오   │                                                       │
│               │                                                       │
│ 설정          │                                                       │
└───────────────┴───────────────────────────────────────────────────────┘
```

공통 규칙:

- 탐색 너비는 고정하고 본문 최대 너비를 제한합니다.
- 현재 단계는 색과 `aria-current`를 함께 사용합니다.
- 상태 메시지는 화면 이동 없이 본문 영역에서 바뀝니다.
- 모바일에서는 탐색을 숨기고 하단의 이전·다음 행동을 고정합니다.

## WF-00 작업 공간 홈

```text
┌───────────────────────────────────────────────────────────────────────┐
│ 안녕하세요. 어떤 커리어를 준비하고 계신가요?                         │
│                                                                       │
│ 지원 직무                       지원 기업                             │
│ (예: AI Product Manager       ) (기업명 입력                       ) │
│                                                                       │
│ [분석 시작]  [예시로 둘러보기]                                       │
├───────────────────────────────────────────────────────────────────────┤
│ 진행 단계                                                             │
│ ○ 01 산업 분석                                           시작 전      │
│ ○ 02 기업 분석                                           시작 전      │
│ ○ 03 직무 분석                                           시작 전      │
│ ○ 04 경험 정리                                           시작 전      │
│ ○ 05 역량 연결                                           시작 전      │
│ ○ 06 인사이트                                            시작 전      │
│ ○ 07 문서화                                              시작 전      │
└───────────────────────────────────────────────────────────────────────┘
```

상태:

- 직무 미입력: 분석 시작 비활성
- 예시 모드: 폼 아래에 `예시 데이터` 표식과 합성 대상 요약
- 복귀 사용자: 완료 단계와 기존 지원 대상 표시

## WF-01 분석 화면

산업·기업·직무가 같은 골격을 공유합니다.

```text
┌───────────────────────────────────────────────────────────────────────┐
│ 직무 분석 · 3 / 7 단계                                                │
│ JD가 요구하는 일과 증명해야 할 역량을 정리합니다.                     │
│                                                                       │
│ 산업              기업명             지원 직무                       │
│ (FinTech        )  (가상금융       )  (AI Product Manager         ) │
│                                                                       │
│ JD 전체 텍스트                                                       │
│ ┌───────────────────────────────────────────────────────────────────┐ │
│ │ 사용자가 실제 공고를 붙여넣는 영역                               │ │
│ └───────────────────────────────────────────────────────────────────┘ │
│ [직무 분석하기]                                                       │
├───────────────────────────────────────────────────────────────────────┤
│ 직무 분석 결과                                      AI 분석 [수정]   │
│ ┌───────────────────────┬───────────────────────────────────────────┐ │
│ │ 직무 한 줄 정의       │ 주요 업무                                 │ │
│ ├───────────────────────┼───────────────────────────────────────────┤ │
│ │ 필수 역량             │ 우대 역량                                 │ │
│ ├───────────────────────┼───────────────────────────────────────────┤ │
│ │ 키워드                │ 경험 탐색 질문                            │ │
│ └───────────────────────┴───────────────────────────────────────────┘ │
│ [← 기업 분석]                                          [경험 정리 →] │
└───────────────────────────────────────────────────────────────────────┘
```

기업 화면 추가 요소:

- 기업 참고자료 textarea
- 결과 아래 `[ ] 기업 분석을 확인했습니다. 문서 작성에 사용합니다.`

## 모바일 셸

```text
┌──────────────────────────────┐
│ 커리어코치            [메뉴] │
├──────────────────────────────┤
│ 브라우저 저장·AI 전송 안내  │
│ {AI 분석 사용 가능}          │
│ [예시로 둘러보기]            │
├──────────────────────────────┤
│ 산업 기업 직무 경험 연결 ...│
│ ━━━  ━━━  ━━━  ━━━  ━━━    │
├──────────────────────────────┤
│ 현재 단계 제목              │
│ 설명                         │
│                              │
│ 입력과 결과가 한 열로 배치   │
│                              │
│                              │
├──────────────────────────────┤
│ [← 이전] [다음 단계       →]│
└──────────────────────────────┘
```

모바일 규칙:

- 최소 기준 너비는 375px입니다.
- 주요 입력과 결과 카드는 한 열로 쌓습니다.
- 이전·다음 행동은 안전 영역을 고려해 하단에 고정합니다.
- 고정 영역이 마지막 입력과 바닥글을 가리지 않도록 여백을 둡니다.
- 터치 목표 높이는 44px 이상으로 유지합니다.
- 긴 단계명은 시각적으로 줄여도 보조기술용 전체 이름은 유지합니다.

## 상세 디자인 전에 확정할 것

1. v1.1 저장 완료 표시를 상단 공통 안내에 둘지 단계 하단에 둘지
2. 비활성 생성 버튼의 누락 조건을 인라인으로 보여줄지 요약 카드로 보여줄지
3. 분석 결과 이력을 현재 결과 위의 탭으로 둘지 설정에서 관리할지
4. 문서 생성 전 선택 정보 요약을 허브에 둘지 각 문서 화면에 유지할지

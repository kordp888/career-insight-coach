# PRD

제품명: AI Career Insight Coach
문서 버전: 1.0
제품 상태: Production 운영 중

## 제품 정의

취업 준비자가 관심 산업, 기업 자료, 실제 JD, 자신의 경험을 한 작업 공간에 입력합니다.
제품은 입력 내용을 단계별로 분석하고 경험과 직무의 연결 근거를 제안합니다. 사용자는
제안된 인사이트를 선택하거나 수정한 뒤 이력서, 자기소개서, 포트폴리오 초안을 만듭니다.

## 문제

취업 준비 과정에서는 산업 조사, 기업 조사, JD 해석, 경험 정리, 문서 작성이 서로 다른
도구와 파일에 흩어집니다. 이때 JD가 요구하는 역량과 본인의 실제 행동 사이 연결이 약해지고,
확인하지 않은 수치나 역할이 문서에 섞일 위험도 커집니다.

대상 사용자는 실제 채용공고에 지원하려는 경력자, 직무 전환자, 프로젝트 경험을 직무 언어로
정리하기 어려운 취업 준비자입니다.

## 제품 원칙

1. 사용자가 입력한 사실을 기준으로 작업합니다.
2. AI의 제안은 사용자가 선택하고 수정할 수 있습니다.
3. 분석 실패를 예시 결과로 감추지 않습니다.
4. 합격 가능성이나 직무 적합도를 숫자로 평가하지 않습니다.
5. 시점에 민감한 정보는 사용자가 공식 자료로 다시 확인합니다.
6. 입력 데이터의 저장 위치와 AI 전송 시점을 화면에서 알립니다.

## 목표

| 목표 | 성공 조건 |
|---|---|
| 첫 가치 도달 | 신규 사용자가 실제 JD 1개와 경험 1개 이상으로 인사이트 후보를 생성 |
| 근거 중심 문서화 | 생성 문서가 선택된 경험과 승인된 인사이트만 사용 |
| 사용자 통제 | 인사이트 승인·수정·제외와 생성 문서 직접 수정이 가능 |
| 안전한 실패 | AI 오류·연결 불가·요청 제한을 구분해 표시하고 실제 데이터를 보존 |
| 작업 지속성 | 새로고침 후 복원, JSON 내보내기·불러오기·전체 삭제가 정상 동작 |

| 제외 범위 | 이유 |

| 실시간 뉴스·시장 검색 | 현재 분석 계약의 범위가 아니며 별도 출처 검증이 필요 |

## 핵심 사용자

### 실제 지원자

실제 기업과 JD에 지원하며 본인의 경험을 근거 있는 문장으로 정리하려는 사용자입니다.

### 탐색 사용자

개인정보를 입력하기 전에 제품의 순서와 결과 형태를 확인하려는 사용자입니다. 명시적으로
`예시로 둘러보기`를 선택했을 때만 합성 데이터를 봅니다.

## 범위

### P0, 현재 제품

산업 분석, 기업 분석, JD 분석, 경험 1~10개 관리, 경험 보완 질문, 역량 연결,
인사이트 승인, 문서 3종 생성, 브라우저 저장, JSON 이동, 예시 공간 분리,
개인정보 안내, 로딩·빈 화면·오류·요청 제한·AI 연결 불가 상태를 포함합니다.

### P1, 다음 개선

| 항목 | 목적 | 수용 기준 |
|---|---|---|
| 단계별 임시저장 시각화 | 저장 여부 불안 감소 | 마지막 저장 시각 또는 저장 완료 상태를 표시 |
| 분석 결과 이력 | 재생성 결과 비교 | 같은 단계의 최근 결과를 최대 3개까지 비교·선택 |
| 완료 조건 안내 | 막힌 이유 이해 | 비활성 버튼 근처에 누락된 입력을 표시 |
| 선택 정보 요약 | 문서 생성 전 오류 방지 | 선택 경험·인사이트·기업 승인 상태를 한 화면에서 검토 |
| 익명 사용 지표 | 실제 이탈 구간 파악 | 입력 본문을 수집하지 않고 단계 진입·완료·오류만 측정 |

### P2, 별도 검토

계정 동기화, JD 버전 비교, 팀 피드백, 면접 준비, 지원 일정 관리, 공식 자료 검색과
출처 인용은 별도 PRD로 분리합니다.

## 성공 지표

현재 Production에는 제품 분석용 이벤트 계측이 없습니다. 아래 수치는 출시 성과가 아니라
v1.1 계측 후 검증할 목표 가설입니다.

| 구분 | 지표 | 목표 가설 | 측정 조건 |
|---|---|---:|---|
| 선행 | 실제 모드 시작 대비 JD 분석 완료율 | 55% 이상 | 14일, 중복 세션 제외 |
| 선행 | JD 분석 완료 대비 인사이트 1개 승인율 | 60% 이상 | 경험 1개 이상 입력 세션 |
| 선행 | 인사이트 승인 대비 문서 1종 생성율 | 70% 이상 | 같은 브라우저 세션 |
| 선행 | AI 요청 오류율 | 5% 이하 | 사용자 취소 제외 |
| 선행 | 무응답 버튼 비율 | 0% | 비활성 이유 안내 포함 |
| 안전 | 실패 후 예시 자동 전환 | 0건 | 모든 AI 화면 |
| 안전 | 선택하지 않은 경험의 문서 포함 | 0건 | 합성 회귀 데이터 검사 |
| 후행 | 7일 이내 작업 재방문율 | 20% 이상 | 익명 로컬 식별자 동의 시 |
| 후행 | 문서 생성 후 직접 수정 비율 | 관찰 후 기준 설정 | 편집 발생 여부만 측정 |

## 제약

- 데이터는 기본적으로 브라우저 localStorage에 저장합니다.
- AI 분석을 누른 입력만 서버 분석 API로 전송합니다.
- 주민등록번호, 계좌번호, 비밀번호, API key 입력 금지 안내를 유지합니다.
- 공개 코드에는 실제 사용자 자료와 비밀키를 저장하지 않습니다.
- 모바일 375px부터 데스크톱 1440px까지 핵심 흐름이 동작해야 합니다.
- 기존 `/demo/*` 주소는 대응하는 `/coach/*`로 이동해야 합니다.

## 출시 기준

- 산업·기업·직무·경험·인사이트·문서 작업이 실제 서버 응답으로 완료됩니다.
- AI 실패 시 오류를 표시하며 합성 예시를 자동 출력하지 않습니다.
- 문서에는 사용자가 선택한 경험과 승인한 인사이트만 전달됩니다.
- 새로고침과 JSON 이동 뒤 작업 상태가 보존됩니다.
- 잘못된 JSON은 기존 데이터를 바꾸지 않고 거부합니다.
- 375·390·430·768·1024·1440px에서 가로 넘침이 없습니다.
- 정상 흐름에서 브라우저 오류가 없습니다.

# UI 상세설계

범위: v1.1 첫 구현 묶음
대상: 자동 저장 상태, 문서 생성 전 확인

## 사용자 문제

입력 내용이 실제로 저장됐는지 화면만 보고 확신하기 어렵습니다. 문서 생성 버튼이 비활성일 때도
어떤 조건이 부족한지 한 문장 안에서 찾아야 했습니다.

## 자동 저장 상태

### 배치

작업 공간 상단의 AI 연결 상태와 같은 행에 배치합니다. 개인정보 안내보다 시각적 우선순위는 낮고,
오류가 발생하면 저장 상태의 색과 문구를 바꿉니다.

### 상태

| 상태 | 문구 | 색 |
|---|---|---|
| 최초 진입 | 입력할 때 자동 저장됩니다. | `color-mint` |
| 저장 성공 | 이 브라우저에 저장됨 | `color-mint` |
| 저장 실패 | 저장 상태를 확인해 주세요. | `color-danger` |

저장 실패 상세 문구는 기존 `role=alert` 영역에 유지합니다. 성공 문구는 `aria-live=polite`로
알리며 입력 필드의 포커스를 바꾸지 않습니다.

## 문서 생성 전 확인

### 배치

문서용 경험과 인사이트 표시 아래, 선택 입력과 생성 버튼 사이에 배치합니다.
배경은 `color-canvas`, 테두리는 `color-line`, 모서리는 `radius-card`를 사용합니다.

### 확인 항목

| 조건 | 이동 경로 | 적용 문서 |
|---|---|---|
| JD 분석 완료 | `/coach/job` | 전체 |
| 문서에 사용할 경험 선택 | `/coach/experience` | 전체 |
| 문서에 사용할 인사이트 선택 | `/coach/insight` | 전체 |
| 기업 분석 사용 확인 | `/coach/company` | 기업 분석이 존재할 때 |
| 자기소개서 질문 입력 | 현재 화면 | 자기소개서 |

완료 항목은 체크 아이콘과 `color-mint`, 미완료 항목은 점선 원과 `color-ink-3`를 사용합니다.
이동 가능한 미완료 항목은 링크로 제공합니다.

### 반응형

| 화면 | 동작 |
|---|---|
| 768px 이상 | 확인 항목을 2열로 배치 |
| 767px 이하 | 한 열로 배치 |

### 상호작용

- 조건이 바뀌면 목록과 생성 버튼 상태가 즉시 갱신됩니다.
- 미완료 링크는 해당 입력 화면으로 이동하며 현재 작업을 보존합니다.
- 모든 항목이 완료되면 안내 문구를 숨기고 생성 버튼을 활성화합니다.
- 기업 분석이 없으면 기업 승인 항목을 표시하지 않습니다.

## 접근성

- 체크 아이콘은 장식으로 처리하고 조건 문구를 텍스트로 제공합니다.
- 안내 영역에 제목을 연결해 스크린리더 탐색 기준을 만듭니다.
- 비활성 버튼만으로 상태를 전달하지 않습니다.
- 미완료 안내는 `role=status`를 사용합니다.
- 링크 포커스 스타일은 전역 `focus-visible` 토큰을 유지합니다.

## 경계 조건

| 조건 | 결과 |
|---|---|
| 선택 경험을 해제해 승인 인사이트의 근거가 사라짐 | 인사이트 조건을 미완료로 변경 |
| 기업 분석 결과만 있고 미승인 | 기업 확인 항목만 미완료 |
| 자기소개서 질문 공백 | 질문 조건 미완료 |
| localStorage 쓰기 실패 | 저장 성공 문구 대신 오류 상태 표시 |
| 예시 모드 | 실제 모드와 같은 저장 상태 구조 사용, 상단 예시 표식 유지 |

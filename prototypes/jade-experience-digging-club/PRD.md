# [최종 PRD] 커리어 웨이브 (Career Wave) - 경험디깅클럽

## 1. 프로젝트 개요
- **서비스 명 (가제):** 커리어 웨이브 (Career Wave) / 경험디깅클럽
- **서비스 정의:** 신입 구직자가 잊고 있던 자신의 경험을 대화형 AI(경험 발굴하기) 혹은 직접 입력(경험 정리하기)을 통해 쉽고 체계적으로 기록하고, 이를 자소서 및 면접에 즉시 활용할 수 있도록 세분화하여 구조화·관리해 주는 취업 준비 필수 유틸리티 서비스
- **주요 해결 과제:** 취준생이 겪는 '기억 안 남 & 막막함'의 진입장벽을 허물고, 파편화된 경험을 날짜, 역할, 기술, 성향 등 세부 항목으로 구체화한 뒤 직무 역량 및 키워드별로 구조화하여 자소서 작성 효율성 극대화

## 2. 문제 정의
- **핵심 문제:**
  1. "기억 안 남 & 막막함": 이력서나 자소서를 쓰려고 하면 막막하고 내가 무슨 경험을 했는지 기억조차 나지 않는 문제
  2. "구조화 및 세분화의 부재": 경험을 나열하긴 했으나 자소서 항목에 녹여낼 디테일한 항목(기간, 과제, 기술, 결과물, 성향 등)이 누락되어 있고, 직무 역량별로 분류되지 않아 매번 새로 작성해야 하는 고통
- **해결 방향:** 대화형 AI를 통한 '경험 발굴하기' 모드와 직관적인 폼 형태의 '경험 정리하기' 듀얼 모드를 제공하여 유저 성향에 맞춘 데이터 수집을 돕고, 시스템이 자동으로 추천 키워드를 도출하여 라이브러리화

## 3. 대상 사용자 (유저 페르소나)
- **타겟:** 스펙은 쌓았는데 정리가 안 된 '준비된 취준생' A군 (24세, 대졸 예정)
- **특징:** 인턴, 공모전, 팀 프로젝트 등 원재료(경험)는 풍부하지만, 이를 체계적으로 분류하지 못해 자소서를 쓸 때마다 헤매는 유형
- **니즈:** 방대한 경험 파편들을 세부 항목별로 깔끔하게 기록하고, 추천 키워드와 함께 직무별로 모아두었다가 필요할 때 꺼내 쓰고 싶어 함

## 4. 핵심 기능 요구사항 (Core Features)
### 듀얼 모드 경험 입력 시스템
1. **[경험 발굴하기 (AI 대화 모드)]** 챗봇과의 대화를 통해 유저의 기억을 이끌어내고, 경험활동 / 기간 / 과제 / 참가자 / 나의역할 / 업무내용 / 희망 결과물(목표) 또는 해결할 문제 / 적용 지식·이론 / 적용 기술 및 기술 적용 부분 / 최종 결과물 내용 / 수행 과정에서 보여준 성향 및 태도 등을 자연스럽게 추출 + 추천 키워드 자동 부착
2. **[경험 정리하기 (직접 입력 모드)]** 위와 동일한 상세 항목들을 유저가 직접 차례대로 입력할 수 있는 폼 제공 + 작성 완료 후 시스템의 분석 및 추천 키워드 자동 부착

### 직무 역량 및 키워드 구조화 (태깅 & 라이브러리)
- 입력·발굴된 경험들을 직무 역량별, 키워드별, 날짜별로 분류 및 태깅하여 라이브러리화

### 자소서 연계형 아카이브 및 공고 마감 관리
- 작성할 자소서 등록 기능 연동
- 공고 마감 전날 알림 푸시 및 채용 사이트 링크 바로 연결 기능

## 5. 사용자 사용 시나리오 (User Journey Scenario)
홈 화면 접속 ➔ [새로운 경험 추가하기] 퀵 버튼 클릭 ➔ [경험 발굴하기(AI 대화)] 또는 [경험 정리하기(직접 입력)] 선택 ➔ 세부 항목(활동, 역할, 기술, 성향 등) 데이터 구축 및 추천 키워드 자동 생성 ➔ 경험 아카이브(라이브러리)에 저장 ➔ 마이페이지에서 자소서 등록 및 공고 마감 알림 관리

## 6. IA 및 메뉴 트리
- **[탭 1: 홈 / 대시보드]**
  - 직관적인 '새로운 경험 추가하기' 퀵 버튼 전면 배치
  - 하위 선택지: [경험 발굴하기 (AI 대화)] / [경험 정리하기 (직접 입력)]
- **[탭 2: 경험 아카이브 (라이브러리)]**
  - 직무 역량별, 키워드별, 날짜별 분류 및 검색 / 필터링 기능 제공
- **[탭 3: 마이페이지]**
  - 기본 프로필 및 데이터 관리
  - 작성할 자소서 등록 기능
  - 공고 마감 전날 알림 푸시 + 채용 사이트 링크 연동 기능
